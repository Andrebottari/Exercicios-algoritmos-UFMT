# 💻 Algoritmos I, II e III — UFMT

Repositório com exercícios e códigos desenvolvidos durante a graduação em **Engenharia da Computação** na **Universidade Federal de Mato Grosso (UFMT)**.

## 📚 Sobre

Aqui estão reunidos alguns dos exercícios propostos pelo professor na disciplina de:

* 🧩 **Algoritmos I**
* 🧩 **Algoritmos II**
* 🧩 **Algoritmos III**

Acredito que todos os códigos foram desenvolvidos em **C**, abordando conceitos fundamentais de programação, lógica, algoritmos e estruturas de dados.

## 🎯 Objetivo

Este repositório tem como objetivo **registrar e preservar parte do meu percurso acadêmico**, reunindo exercícios realizados ao longo das disciplinas de algoritmos durante a graduação.

Os códigos representam diferentes etapas do aprendizado e podem conter desde exercícios introdutórios até implementações de conceitos mais avançados.

## 🛠️ Tecnologias

* 🔵 **C**
* 🖥️ Programação estruturada
* 🧠 Algoritmos e lógica de programação
* 📊 Estruturas de dados
